## 本次修复说明 / Bug Fixes

### 阶段一修复

1. **`C/Graph/GraphPrim/graphmatrixutil.c` - Prim 算法 malloc 大小错误及 min/v 逻辑错误**
   - 原始代码：`malloc(sizeof(graphMatrix->size))` 只分配了 4 字节（sizeof(int)），而非 `size` 个 int 的空间
   - 修复为：`malloc(sizeof(int) * graphMatrix->size)`（`component`、`distance`、`neighbor` 三处）
   - 同时修复了找最小距离时 `v` 和 `min` 的更新逻辑：将两者更新放在同一 `if` 块内，避免只更新 `min` 而不更新 `v`

2. **`C/Graph/CriticalPath(Need_Fix)/criticalpath.c` - 关键路径最迟发生时间计算逻辑错误**
   - `eventLatestTime()` 函数中，最迟发生时间应取"最小值减去权值"，而非"最大值加上权值"
   - 修复：将 `<` 改为 `>`，`+` 改为 `-`，即：`if (latestTime[...] > latestTime[nodeNum] - weight)`

3. **`C++/MyMapModel/MapAdvPrim.cpp` - 析构函数内存泄漏**
   - 构造函数中 `new Edge[m_iCapacity - 1]` 分配的 `m_pEdge` 在析构函数中未释放
   - 修复：在析构函数中补充 `delete[] m_pEdge`

4. **`C++/MyTreeModel/TreeBasic.cpp` - `AddNode()` 中地址比较逻辑错误**
   - `&m_pTree[nodeIndex] == 0` 永远为假（数组元素地址不可能为 0）
   - 修复：改为 `m_pTree[nodeIndex] == 0`，正确检查元素值是否为 0

## 编译运行说明 / How to Compile

以 Linux / gcc / g++ 为例，进入对应项目目录后：

**C 语言项目：**
```bash
# 以 C/StackAndQueue/LinkedStack 为例
cd C/StackAndQueue/LinkedStack
gcc LinkedStack.c Demo.c -o demo
./demo
```

**C 排序算法：**
```bash
cd C/Sort
gcc Sort.c main.c -o sort_demo
./sort_demo
```

**C++ 语言项目：**
```bash
# 以 C++/MyStackModel 为例
cd C++/MyStackModel
g++ MyStackBasic.cpp StackModelDemo.cpp -o demo
./demo
```

> **注意：** 部分 C 文件使用了 `scanf_s`（MSVC 专用），在 Linux/gcc 下需将其替换为 `scanf`。
